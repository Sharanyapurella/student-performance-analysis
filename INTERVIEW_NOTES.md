# Fresher Interview Notes

## 1. What is Pandas?
Pandas is a Python library used to read, clean, analyze and work with tabular data.

## 2. What is NumPy?
NumPy is used for numerical operations and arrays in Python.

## 3. What is EDA?
EDA means Exploratory Data Analysis. It is the process of understanding data using statistics and graphs.

## 4. What are features?
Features are the input columns used by the ML model. Here they are study hours, attendance, previous marks, assignment score and sleep hours.

## 5. What is the target?
The target is the value we want to predict. Here the target is Final_Marks.

## 6. Why Linear Regression?
Because Final_Marks is a numerical value and Linear Regression is simple and suitable for learning the relationship between input factors and a numerical output.

## 7. What is train_test_split?
It divides the dataset into training data and testing data. The model learns from training data and is evaluated on unseen testing data.

## 8. What is MAE?
Mean Absolute Error shows the average absolute difference between actual and predicted values. Lower is better.

## 9. What is R2 score?
R2 indicates how well the model explains variation in the target. A value closer to 1 generally indicates a better fit.

## 10. Simple project explanation
"I created a Student Performance Analysis and Prediction project using Python. I used Pandas and NumPy for data processing, Matplotlib and Seaborn for visualization, and Scikit-learn for machine learning. I analyzed study hours, attendance, previous marks, assignment scores and sleep hours. Finally, I trained a Linear Regression model and used it to predict final marks for a new student."
